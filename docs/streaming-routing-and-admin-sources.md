# 流式输出、意图边界与管理端溯源

2026-10-19 更新。

## 流式行为

原 HTTP 接口使用 SSE，但模型先完整生成、审核，再按 12 字切分发送，因此无法边生成边展示。现在 normal_chat / policy_answer / support / monitored_chat / safety_support 全部直接调用供应商流式 API，在独立工作线程运行 Agent 和数据库操作，以异步队列发送增量正文；模型开始前先返回状态，每 10 秒发送心跳，关闭代理缓冲。

所有模式实时发送，不再以情绪或风险等级为由缓冲完整正文。输入风险评估及会话状态仍在模型回答前落库；HIGH 先发送固定安全引导，监测模式先发送简短关心近况的开场，再增量发送模型正文，提示词要求不重复开场。

流内同步使用原有内部标签规则，保留短尾部，避免标签跨 token 泄露。HIGH 的数字串完整保留到可检查时，再与实际上下文中具有链接且非演示资料的电话号码匹配，未核实长号码在发送前替换为占位文字；最终复核使用同一套号码提取规则。结束后仍由原 SafetyAgent 和 CoordinatorAgent 完成规则复核和采纳。已发送文字无法撤回，因此完整复核属于结束检查；发送前检查限于上述本地规则，不等于完整语义审核，也不新增事实核验 Agent 或每次模型打分。

断线会取消上游模型，保存已交付给 HTTP 生成器的正文前缀，标记 INTERRUPTED，并保留实际 current/carryover/effective 风险及状态；需要报告与工具任务时仍执行，不因用户断线丢失预警计划；服务端无法证明浏览器已实际读到每个字节。中途供应商失败保留正文并说明中断，不再发起第二次生成。没有文件时返回固定提示，不调用回答模型编造规则；这种短提示无需模型流式。

## 意图边界

| 输入 | 入口 | 校园政策 RAG |
|---|---|---|
| 你好、讲个笑话、解释 Python 字典 | CHAT | 不调用 |
| 帮我写报销说明邮件、答辩怎么准备 | CHAT | 不调用 |
| 什么是奖学金 | CHAT | 不调用 |
| 本校奖学金申请条件是什么 | CONSULT | 调用 |
| 研究生出差餐补每天多少 | CONSULT | 调用 |
| 上述出差咨询后追问“那住宿费呢” | CONSULT | 调用 |
| 出差咨询后“那给我讲个笑话吧” | CHAT | 不调用 |
| 情绪困扰、危险表达 | RISK | 按原安全链路需要使用支持资料 |

CONSULT 要求校园具体业务对象与规则、流程、标准、时间或联系信息需求同时成立；“咨询一下”“如何”“办理”等单词不能单独触发。通用写作、编程、解释、经验建议优先 CHAT；硬性危险信号始终先进入安全路径。模型返回 CONSULT 也需满足业务依据，不能将其作为所有非风险输入的默认值。具体政策追问可承接历史，泛指追问仅承接最近话题，避免旧政策话题持续污染路由。判断原因与 requiresPolicyRetrieval 进入后台 trace。

规则仍需随真实表达的离线样本补充，不能把本轮测试通过理解为覆盖所有自然语言。

## 来源访问与关联

学生流式和历史接口不发送 sources/traceId，页面不展示资料卡片。管理端“对话与运行记录”及“会话档案审阅”展示每条回答及可展开的资料原文、版本、章节、页码和原文链接，接口继续受管理员权限保护。提示词要求正文不主动附带文件名和引用清单。

新增可空 chat_messages.agent_trace_id，将用户消息和助手回复绑定到同一条运行。启动时对 MySQL/旧 SQLite 增补列与索引，保留原数据。旧消息使用同会话、同输入、时间窗口及已采纳正文匹配 trace；旧记录缺少关联时明确提示，不按当前知识库补造来源。保存的是实际传入模型的检索上下文，不代表逐句事实已被证明。

## 验证

- 全模式流式更新后 144 项 Python 回归、6 组工程检查和 9 个 mock 场景通过；前端键盘行为未改动。
- 首轮隔离 SQLite、真实云端模型完成四轮 HTTP SSE 验证：普通 Python 解释第 3.87 秒收到首段、第 7.90 秒收到末段，共 103 个正文事件；政策咨询在隔离测试文件入库后第 4.20 秒收到首段、第 5.31 秒收到末段。
- 全模式更新后真实云端模型 6/6 HTTP 场景通过：含缺文件固定提示、CHAT、情绪支持、HIGH、MONITORING、有资料政策。HIGH 的固定引导在 0.013 秒发出，模型正文从 1.444 秒持续输出到 3.819 秒；监测模式模型正文从 6.236 秒持续到 13.151 秒。仅为本轮网络和样本的观察值，不是延迟保证。
- 政策后切换讲笑话回到 CHAT，资料数为 0；有资料的政策回答学生无来源字段，管理端保存 3 个原文片段，回复正文与流式拼接一致。
- 自动测试覆盖模型生成未结束即收到首段、跨 token 标签拦截、中途失败、断线主动取消和 INTERRUPTED 保存、LOW/MEDIUM 情绪支持、HIGH、监测、政策回答均在生成结束前返回模型正文；高风险断线保留正确风险、报告和工具计划。
- 浏览器核对管理员运行卡片和历史的逐条来源，以及学生历史无来源卡片。

真实测试仅写入独立测试库，虚构金额明确标记为测试，未写入业务政策库，不代表真实学校政策准确率。全模式真实 HTTP 记录另见 target/all-stream-live-verification.json。其他证据为 target/real-stream-verification.json、target/stream-routing-tests.log、target/stream-routing-harness.log、target/stream-routing-mock-eval.json。
