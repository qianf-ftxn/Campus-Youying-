# macOS 一键启动

更新日期：2026-10-19。

双击桌面 `mindbridge.command`。该文件与 `ReplyU` 文件夹保持在同一目录即可；项目脚本使用自己的路径定位目录。

## 实际启动顺序

1. 补充 Finder 启动 Terminal 时可能缺少的 Homebrew / Docker 命令路径。
2. 使用项目 `.venv`；缺失时用已安装的 Python 3.11 / 3.12 创建，并补齐 Python 依赖。已有 `.env` 保留。
3. 检查重复启动与端口占用。同一端口只保留一个启动进程；已有服务就绪后直接打开页面，其他应用占用端口时明确报错，不终止其他应用。
4. 按 `.env` 选择依赖。本机配置的 MySQL 13306、Redis 16379 由项目 Docker Compose 启动；Docker Desktop 未启动时自动打开并等待。其他地址不接管，直接检查连接。
5. 等待真实数据库 `SELECT 1` 与 Redis `PING` 成功。
6. 检查云端模型鉴权、Chroma 与实际 Embedding 请求。当前配置使用云端模型，无需本地 Ollama；若配置 Ollama，会按需启动本地服务并检查所配置模型已安装。
7. 启动 FastAPI。该进程同时提供登录、学生端、管理端、后端 API，以及按 `.env` 开关启动的工具队列与记忆维护线程。独立 MCP stdio 工具服务仍由原客户端按需启动，不需要常驻额外终端。
8. 等待 `/actuator/ready` 通过，并确认主页可访问，最后自动打开 `http://127.0.0.1:7070`。不再固定等待五秒就打开页面。

默认等待 Docker 最多 180 秒、数据库 120 秒、Redis 90 秒、应用 300 秒；失败会明确停止本次启动，并保留终端与日志供检查。已有 `.env` 禁用的功能会显示 `DISABLED`，不会被脚本擅自改成启用；当前机器的工具队列、记忆维护与向量检索均启用。

模型及 Embedding 启动探测会对连接失败、超时、限流和供应商临时错误重试最多 3 次，鉴权失败不会盲目重试；探测错误会写入启动日志，不记录 API Key。

## 使用与日志

- 学生入口：`http://127.0.0.1:7070/`，演示账号 `student / student123`。
- 管理端使用 `admin / admin123`；已有账户沿用原密码，不重置用户数据。
- 后端日志：`target/launcher/startup.log`。
- 终端需要保留；Ctrl+C 或关闭初次启动窗口会停止本次后端和本次启动的 Ollama，MySQL / Redis 容器继续运行，数据卷保留。
- 后续再次双击会自动恢复后端，无需手动启动各组件。
- 命令行入口：`bash scripts/one-click.sh`；`--no-browser` 用于验证，`--port 7071` 可指定其他端口。不要同时使用多个端口运行同一业务库的后台工作进程。
