# 西电官方资料入库与分发

资料包及逐份来源见 [knowledge/xidian/README.md](../knowledge/xidian/README.md)。本次核查日期 2026-10-19，收集 55 份公开官方资料，默认参与检索 49 份；4 份因正文提取或现行性未核实留作草稿，2 份旧年度通知归档。没有补入演示政策。

原文、提取文本及清单保存在项目文件中，首次启动自动校验与导入，Docker 镜像也包含资料目录；无需分发本机 SQL 数据或 Chroma 文件。文件发生缺失、修改或哈希不匹配时日志给出明确原因，管理端知识状态接口也报告缺失文件。文档未导入时，咨询继续返回缺资料提示，不猜测具体校规。

导入遵循原有学校、版本、状态和日期过滤。同版本再次启动不重复切块，管理员在后台停用的同版资料不会重启复活；若要启用，管理员明确执行启用操作。资料更新应使用内容哈希的新版本，保留旧来源版本与历史回答 trace，不拿新的文件替换过去的回答依据。新版本内容不同但人工沿用同一版本号会拒绝入库。

在全新数据库、关闭向量和无网络抓取的条件下，已验证从仓库文本重建父子知识块、重复导入幂等、管理员归档保留、学校隔离、缺文件/哈希篡改/路径越界/非官方来源拒绝，以及请销假、校外住宿、硕士学习年限和转导师问题的基本召回。它们是工程与检索冒烟验证，不是全部政策问答准确率验收。

Embedding 仍来自用户配置的兼容接口；公共法规原文不需要每次向官网获取。使用不同模型、数据库 ID 或新机器时应重新生成向量。首次索引可能较慢，启动等待上限已增加到 900 秒。

财务处目前要求校内访问，现行研究生差旅、餐补标准尚未得到核实；工作餐 PDF 与差旅伙食补助不是同一业务，工作餐资料仅保存为待核对草稿。不要用第三方转载或教师课题组个人待遇作为全校政策。

验证结果：151 项 Python 回归通过，6 组工程 harness 通过；Git 导出的全新副本不带 .env、聊天数据库或 Chroma，自动启动导入后得到 66 份文档（含原有 11 份支持资料）与 2985 个父子块，重复启动数量不变。真实模型在隔离 SQLite 中完成请销假、校外住宿和缺失差旅标准三个问答场景；本机也完成真实 Embedding 入库，未改写原有会话、消息、报告和风险事件。

本次同时补齐了转导师、学位复核、校外住宿等新增制度主题的路由词，避免有正式资料的问题误入通用聊天。

当前文件夹原先没有 Git 记录和远程地址。提交前需排除 .env、data、target、虚拟环境、私钥和模型大文件；原始资料目录 knowledge/ 必须随源码一并提交。GitHub 发布还需要明确的目标仓库。
