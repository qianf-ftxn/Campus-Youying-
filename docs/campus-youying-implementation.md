## 已完成的行为

- CHAT 保留普通交流；明确政策问题进入 CONSULT；情绪支持与危险表达进入 RISK，安全等级单独评估。
- 分类、规则回退、mock 和原心理评测样本标签同步适配；分享“报销办完了”与询问政策区分。
- 普通 CONSULT 不再因为标签本身生成心理报告，不加载心理支持专用 Skills。
- 政策回答模式基于实际证据，明确不足、冲突和演示资料，不承诺派单、转接或提交申请。
- 原五 Agent 的共享黑板、任务认领、安全审查和最终采纳保留；普通 CHAT 也等待历史上下文加载。
- 原始业务意图在 trace 中保留，安全覆盖不丢失用户本来询问的业务类型。
- 父块按主标题/条款组织，子块在父块内切分；两层均向量化，分开召回配额。
- 父向量、子向量、子块 BM25 归并到父块，归一化融合、去重；不再使用相邻块扩展。
- 规则重排保留开关，当前关闭；现有样本不足以宣称某参数组合在真实政策上最优。
- 文档元数据、版本、领域、学校、有效日期与状态管理，父子块预览和启用/归档接口完成。
- 新版本启用后旧版归档；未来文件先入草稿，日期到达后人工启用；旧内容不删除。
- MySQL/已有 SQLite 的增补迁移、旧平面知识向父子结构迁移完成，旧块保留供追溯。
- 向量索引按接口/模型隔离；全量重建使用 staging collection、校验后原子切换，失败保留旧索引。
- 查询同时过滤数据库允许的块 ID，停用版本即使向量仍存在也不会进入召回结果。
- 知识预算跳过无法容纳的父块并记录原因，不再因首项过长直接丢掉后续所有结果。
- 来源已改为管理端逐条回复查看，学生 SSE 和历史接口均不包含来源字段；消息精确关联 trace，重试复用当时来源。详见 [最新流式与路由说明](streaming-routing-and-admin-sources.md)。
- 管理端增加普通对话运行记录与统计，和支持报告分开；可查看检索、协作和会话。
- 保留 12→8 摘要压缩、失败不推进游标、后台重试；安全记忆按用户和会话联合隔离。
- 摘要提示词扩展为通用校园语境；检索改写使用累计摘要和近期概览，保留身份与条件更正。
- 修复 mock 摘要对大写 USER 角色的兼容，覆盖压缩后政策追问。
- 模型故障/空正文返回明确回退，记录 `generationError`；增加模型调用次数及耗时、Agent 执行耗时记录。
- 沿用安全审查，补充未经来源核实的长联系电话规则和引用语境测试；未新增政策核验 Agent 或每轮模型打分。
- 开发启动脚本优先项目虚拟环境，不再覆盖 `.env` 的 Provider；Docker 补充 Skills 和环境接入。

## 配置和依赖调整

已更新 `.env.example` 和当前机器与检索有关的非敏感配置：父块目标 1000 字符、子块 300 字符、长句重叠 40 字符；融合初值 0.30/0.35/0.35；知识预算 4000 tokens；规则重排关闭。它们是可调起点。

当前机器的旧聊天模型别名 `deepseek-v4-flash` 返回 404。通过现有服务端模型目录与实际请求确认后，改为同系列可用快照 `deepseek-v4-flash-0731`。保留原 `text-embedding-v4` 和其他接入配置。

为当前兼容服务设置 `OPENAI_ENABLE_THINKING=false`，解决思考耗尽 512-token 输出预算、正文为空的问题。程序默认不向未配置此项的供应商发送该参数。

Chroma 0.5 与原虚拟环境 posthog 7 的旧 capture API 不兼容，已加入 `posthog>=2.4.0,<4.0.0` 约束，并在本地虚拟环境安装 3.25.0。匿名遥测在 Chroma 客户端设置中关闭。未把任何密钥写入文档或报告。

## 正式资料接入

1. 配置 `CAMPUS_NAME`；默认支持知识和演示指南随该配置接入，已上传的正式文件保留其学校元数据。
2. 准备本校校规、差旅报销等正式文本；PDF 表格和扫描件先人工核对或转为可靠文本/Markdown。
3. 管理端选择 policy 领域，填写发布部门、版本、原文 URL 和有效日期；演示上传入口已移除，原演示政策不再自动导入。
4. 预览父块是否同时保留标准、适用条件和例外，核对子块与父块关联。
5. 建立人工核对的标准问题和独立保留集，标到版本与条款；测试无答案、多轮、更正与例外。
6. 比较重排开关、切块和融合参数，结合检索与实际回答结果决定正式配置。

## 保留的边界

- 无实时教务/财务个人数据接口，无自动派单、审批或跨部门办理能力。
- 无扫描 PDF OCR 和复杂 PDF 表格重建保证；Markdown 表格可保留原文结构。
- 无跨所有聊天的通用用户画像，无 Agent 中途执行恢复。
- 无每次政策回答的独立模型事实核验；基础安全审查也不构成完整的语义安全证明。
- 当前日期与版本激活不会自动推断适用年级、专业和经费条件；资料与用户输入不足时仍需澄清。
