# 冻结协议后的前瞻评测：异构裁判与60道来源隔离候选题

本轮完成了原75题的原文位置/版本校验和评分口径自查、15道已知难题的三组问答回归，以及协议冻结后新增60题的三组对比。前瞻阶段共180份真实模型回答，生成使用DeepSeek，答案质量和事实支持判定使用另一模型家族Qwen。

结论是：现有父子块方案在这批候选题上的可回答题自动符合数与原始平面方案相同，生成输入token少15.72%。语义重排和精简回答原型提高了自动忠实度及资料不足处理表现，但没有证明回答正确率提升，计入重排后完整推理输入token约为现有父子块方案的3.99倍，因此保留现有默认方案。

## 数据、协议和裁判

- 开发集仍为75题。另存 `reviewed_dev_v3.json`，仅将D13“通常分流时间”之外的个别大类例外标为可选，并标记跨制度适用问题待人工确认。原始25题、扩展75题及此前报告均保留。
- 75题全部运行检索对照；问答开发回归预先选定15道已知难题，三组45份评分记录，其中两组30份旧回答按完整请求指纹复用，只新增生成15份原型回答。该定向回归不代表75题整体分布。
- 在开发回归后冻结参数和提示词，再编写60道前瞻候选题：48题可回答，10题应拒绝下达所请求的具体结论，2题应先澄清。五类场景各12题，55个标注证据单元，12个证据族。
- 新题标准答案及负例检查涉及的12份文档，与开发75题的24份标准证据文档不重合。知识库仍为同一批49份快照，并没有向检索系统隐藏这些文档；这种隔离针对题目和标注来源，不是新文档冷启动测试，也不保证已识别所有跨文档同义规则。
- 生成模型固定 `deepseek-v4-flash-0731`，质量及NLI裁判固定 `qwen3.8-flash`。现有接口实际支持这两个模型，复用了已配置凭据；没有改动私有密钥。180份生成响应的模型标识均为DeepSeek，180份质量评分响应均为Qwen。少量事实评分由有完整日志的逐项补评组装。
- 事实提取与反推问题仍用DeepSeek；事实是否被取回资料支持由Qwen判断，且不提供参考答案。异构裁判降低同模型自评风险，但不构成人工金标准。
- 60题全部保持 `pending_human`，没有把AI自查标成“人工批准”。快照原文一致性不等于现行政策有效性核验。

冻结协议及摘要绑定分别位于 `app/policy_eval/frozen_protocol_v3.json` 和 `heldout_candidate_v3.json`。测试运行后没有修改题目、答案、模型、检索/生成提示词或排序参数；只处理API/JSON/逐字引文定位失败，原始输出、拒收输出和补评均保留。

## 三组固定条件

共用2026-10-19快照、`text-embedding-v4`、相同问题与用户历史、K=5、4000估算知识token预算、相同生成模型、温度0及512输出token上限。全部180份回答均正常结束，无长度截断。

| 方案 | 检索与回答 |
|---|---|
| 原始平面混合 | 512/64窗口、向量/BM25融合、原始规则重排和首条邻块扩展；原提示词 |
| 现有父子混合 | hierarchical-v2；父/子向量及子BM25各16候选，权重0.30/0.35/0.35；原提示词 |
| 新原型 | 在现有融合池前32候选内由聊天模型语义重排/过滤，最多选5块；回答逐项覆盖必要限制并减少无依据扩写 |

新原型可在无适用资料时返回少于5块或空集，并不要求凑满。它采用聊天模型语义重排，不是专用cross-encoder重排API，也不是原有的关键词规则重排。本轮接口的专用rerank路径未通过可用性验证。

本轮问题及裁判均与上一轮不同，不能把这里的Faithfulness与旧75题分数直接相减，称为系统进步或退步。

## 错例、标注争议和不确定性

1. **H-X02，原始与现有方案**：取回了“正文10日”和“附件10工作日”，却自行断言“正文优先”，现有方案还写错条号。新原型指出了冲突。该题比较快照内的文字差异，实际制度适用解释仍需业务审核。
2. **H-X06，新原型**：给出了成果形式和证明材料，但没有显式写出同行鉴定/评审及推广应用或效益条件。自动裁判按完整要点扣分；问题是否必须覆盖这一附加审核条件，也应人工确认。
3. **H-M09，三组都扣分**：三组均正确回答“800元、导师承担、学校无配套”，却因没有额外重复“不保证实际到账”被判一条未覆盖。这与预设的“负约束不要求逐字重述”规则存在冲突，属于高优先级裁判/标注复核项，不能称为三组都答错了金额。
4. **H-X12，新原型扣分**：已正确回答学业与外语两项、明确限定“只看这两项”，仍被裁判以没有另写“不保证最终资格”扣分，也应复核负约束是否满足。
5. **H-U08/H-U09**：缺少退役原因或抽检类型/结果/次数时，需要先澄清；部分回答先列出规则再追问，被严格行为口径判为不符合“先澄清”。只有2题，不能据此推广整体澄清能力。

以上争议没有在看到分数后悄悄改标或删题。原始表、逐要点判定、裁判理由和回答均保存；人工修订时须说明原因并对三组用同一新口径重算。

以12个证据族为配对重采样单位，5000次、固定随机种子，新原型相对原始方案的可回答题符合率差值为-2.08个百分点，条件95%区间为[-8.33,+4.17]个百分点，未支持符合率提升。Faithfulness差值为+14.11个百分点，条件区间[+7.29,+21.34]；该区间不包含事实抽取、标注或裁判误差，仍不能替代人审。

现有父子块与原始方案在48道可回答题上的逐题通过标签相同，因此经验配对bootstrap的差值区间退化为[0,0]。这只描述这批自动标签，不能证明总体正确率等效或未来不会出现差异。

## 已完成和仍缺的部分

已完成：证据版本/位置校验、D13必要/可选要点区分、来源隔离的新题、开发后冻结协议、异构模型裁判、三组真实回答、完整推理token核算、证据族重采样和可复核产物。业务默认仍使用原有提示词和父子检索，没有自动启用实验原型。

仍缺：人工业务审核及争议裁判复核。全135题均未被冒充为人工金标准。本轮没有访问官网重新核实所有制度当日有效性，也没有覆盖生产查询改写、真实多智能体运行、个人系统接入或线上性能验收。

目前可以支持的简历表述是：构建带原文证据和冻结协议的评测流程、增加60道来源隔离候选题、用异构模型裁判对比三组方案，并在这批测试中将父子方案的生成输入token减少15.72%。关于最终准确率提升，应等人工复核后再决定。
